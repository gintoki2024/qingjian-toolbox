青简工具箱 0.12.1 · Mac 试用版

本轮更新（0.12.1，准备发布）
与Windows 0.11.4同步格式转换改良。轮盘每页最多六项，目标不超过六项时同页
显示，超过六项先排满再翻页；常用格式优先，保留拖拽滚轮与按钮翻页。
移除PDF转Excel/CSV；文字型PDF仍可转Word或提取文字，纯扫描件明确提示。
表格支持多工作表导出、独立读写编码与分隔符，保护编号前导零和长数字文本；
没有缓存计算值的公式明确提示重算保存，不输出误导结果。
图片质量、大小、背景及PDF图片DPI等适用参数可记忆，预览后台执行；ZIP打包
使用独立入口。结果窗口支持逐项打开多个结果和仅重试失败来源。
修复Mac文档导出PDF时中文缺字及新生成文档标题复制顺序异常的问题。
详细功能与限制见“程序文件/转换格式说明.txt”。本轮Mac原生构建和验收结果
见最终发行随附的MACOS_VALIDATION.txt，不以Windows离屏检查代替Mac验证。

适用系统
macOS 14.4 或更新系统；支持苹果芯片 arm64 和 Intel x86_64。
源码包自动识别处理器；完整运行包须选择与电脑处理器对应的版本。

启动
1. 完整解压到本地文件夹，保留启动器、使用说明.txt、程序文件三项。
2. 双击“启动青简工具箱.command”。源代码版首次启动先选择：
   1 复用已有 Python：已有兼容组件直接使用，缺项补入该 Python 的标准环境。
   2 独立部署 Python：自动下载可移动 Python，不改系统 Python 或全局 PATH。
3. 按提示选择组件位置；可以直接回车采用建议目录，也可选择其他磁盘。
   该位置存放转换引擎、下载缓存、临时文件和日志，独立于源码包。
   复用已有 Python 时，Python 包仍补到该解释器的标准环境，其他使用同一
   Python 的程序可共用。系统或 Homebrew 管理的 Python 若缺包，不强行修改；
   此时重新选择独立部署，或使用已完整的其他 Python。
4. 初始化完成后界面独立运行，关闭准备窗口不会关闭工具箱或提醒小窗。

网络与升级
轻量源码首次补缺需要联网，之后可以离线使用。只下载缺少或不兼容的组件。
下载使用固定大小和 SHA256 校验，并保留官方来源与国内镜像备用。
升级时替换源码文件夹即可；保留首次选择的外部共享环境，不要删除它。
环境位置的小型索引保存在用户 Library/Application Support/QingjianLocal，
不会把大型组件重新放到系统盘。需要重新选择时，在终端运行启动器并加上
--choose-environment。
完整运行包含 Python、依赖和全部转换引擎，正常启动不会联网补组件。

使用与保存
中文功能分组、公文格式、多组脱敏规则与本地记忆库、检索与查重结果窗口、
组合流程、PPT/Word 模板填充、记事双小窗与转换浮窗保持原有工作方式。
可在外观设置调整透明度与吸附。Mac 使用系统中文字体作为默认回退，
自定义过的字体保持原设置；与 Windows 字体不同可能影响文档分页。
网页链接转 Word 访问在线网页时需要网络；本地网页和文件转换可离线完成。
处理结果使用副本，不覆盖原件。记事和脱敏规则保存在本机用户数据目录。

首次打开与诊断
此版本未提供 Apple Developer ID 签名及 Apple 公证。首次安全提示须由使用者
按系统流程处理；仅在确认来源可信、文件未被篡改且符合所在组织要求后继续。
macOS 14.4 及更新系统统一使用逐应用入口：
1. 先尝试打开启动器；若提示无法验证开发者或无法检查恶意软件，关闭该提示。
2. 打开苹果菜单中的“系统设置”→“隐私与安全性”，向下找到“安全性”。
3. 核对被阻止项目的名称；若系统提供“仍要打开”，选择它，再按提示确认“打开”。
   这只为该项目建立例外，不更改全局安全设置。没有该按钮或公司策略不允许时，
   请联系管理员；若提示“将损坏电脑”或“已损坏”，不要按普通开发者提示处理。
macOS 15 Sequoia 起，Control 点按／右键“打开”不再用于覆盖这类 Gatekeeper
检查；macOS 26 也按上述“隐私与安全性”的系统入口处理。
启动器不会自动关闭 Gatekeeper、防护或隔离机制，不删除 quarantine 隔离属性，
本身不请求管理员权限。系统逐应用授权时可能另外要求身份确认。
若文件没有执行权限，可在终端用 /bin/bash 运行该 .command 文件。
若仍遇到安全拦截，继续按上述系统流程处理。
准备失败先查看所选组件位置中的 logs；不要删除共享环境后反复下载。
需要环境检查时可在已选择的 Python 下执行：
python3 程序文件/bootstrap_macos.py --check-environment --home 组件绝对路径
这项检查不会安装组件。
