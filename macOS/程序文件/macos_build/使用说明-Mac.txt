青简工具箱 Mac 版

适用范围
macOS 14.4 或更新版本；分别支持 Apple 芯片（arm64）与 Intel（x86_64）。
轻量源码包含两种架构的环境准备清单，完整包须选择与电脑一致的架构。

打开方式
完整解压后，打开“启动青简工具箱.command”。根目录保持启动器、使用说明、程序文件三项；移动时请移动整个文件夹。
如系统显示无法确认开发者，请按所在组织的软件使用要求处理。本工具不会修改系统安全设置或请求管理员权限。

轻量源码包
首次打开可选择借用已有兼容 Python，或选择存放备用 Python 和转换组件的位置。可复用的环境直接使用，只补齐缺项；首次准备需要联网，完成后可以离线使用。
自选位置保留在程序包外，后续升级不会因删除旧程序文件夹而重复下载。选择本机 Python 时，Python 组件安装在该解释器环境；原生转换引擎、缓存及日志放在选定目录。
程序不会更改系统 PATH、全局 pip 配置，也不会自动改动系统管理的 Python 环境。

完整运行包
内含本架构的可移动 Python、第三方模块及原生转换引擎，不要求电脑预装 Python、Java、LibreOffice、7zip 或 Ghostscript。启动时只做本地检查，不联网补齐。缺件时请重新解压完整包。

日常操作
主窗口为中文工具入口，子功能可返回上一级。记事、事项与快速转换可独立显示。
文件处理结果保持原件，另存为新文件。网页链接转 Word 访问在线网页时仍需网络；本地网页及本地文档处理可离线运行。
字体和文档排版受本机可用字体影响；与 Windows 专有字体不同的 Mac 字体可能造成换行或分页差异。
Mac 毛玻璃、窗口吸附及拖拽表现以实际系统支持为准。转换成功率和页面验证以随版本提供的真实 Mac 验收报告为准。

数据与退出
事项、常用脱敏规则及偏好保存于当前用户数据目录；发行包不包含个人事项或真实办公资料。
记事窗口可独立使用，关闭主窗口后若仍有小窗，需关闭这些窗口或使用程序的退出操作才能完全退出。
正常启动后准备窗口可以关闭；它不会连带关闭主界面与小窗。

许可与维护
程序文件内保留第三方许可、来源及必要源码说明。源码可用于继续维护；Mac 完整包必须在对应架构的真实 macOS 环境构建并验收，不能从 Windows 运行时直接转换。
