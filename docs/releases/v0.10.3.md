# 青简工具箱 v0.10.3

中文本地办公工具箱，重点提供公文批处理、材料核查、拖拽格式转换和独立记事提醒。

## 下载哪个？

| 附件 | 使用方式 |
| --- | --- |
| **QingjianToolbox-v0.10.3-Windows-x64-Full.zip** | 完整运行包，内置 Python 与本地转换组件；完整解压后双击 CMD，首次也无需下载环境。 |
| **QingjianToolbox-v0.10.3-Source-SharedRuntimeFix.zip** | 轻量源码包，复用兼容的本机 Python，缺项自动联网补齐；无 Python 时也能按提示准备，可选部署盘。 |
| **SHA256SUMS.txt** | 两个下载包的完整性校验值。 |

请下载上方命名的附件，GitHub 自动生成的 Source code 是开发仓库快照。适用 Windows 10（1809+）/11 x64。

## 本版内容

- 整合中文界面优化，首页上方工具分组，下方图片、文字、待办三选一。
- 记事事项可明确输入预约日期与 24 小时制小时分钟，保留定期及提前提醒。
- 转换浮窗支持拖住文件时滚轮翻页；本地转换输出到原文件夹，重名自动编号。
- 源码启动完成后退出准备 CMD，界面、转换和记事小窗独立运行。
- 源码可复用所选 Python 及包外共享引擎，记住位置；旧包内组件尚在时先校验迁移，再删除旧源码。

完整包沿用正常运行的 v0.10.3，源码额外含启动与共享环境修正，两者 60 个业务文件一致。公开下载副本只整理压缩包结构、根说明与许可导航，并移除构建机路径记录，未改变程序逻辑。

## 使用提示

完整解压后根目录为启动青简工具箱.cmd、使用说明.txt、程序文件三项。源码环境补齐后可离线处理本地文件；网页链接功能仍需网络。更新时保留包外共享环境，删除或损坏的组件仍需重新补齐。

自有代码采用 MIT，第三方各按自身许可；具体来源、许可和适用源码材料见仓库与包内说明。此前通过 248 项相关回归和 57 项功能自检，公开副本另做成员字节与压缩包完整性核验。
